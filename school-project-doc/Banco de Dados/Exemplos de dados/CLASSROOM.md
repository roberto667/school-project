# Turma

Tabela `classrooms`. Cada turma referencia um grau escolar e armazena o ano letivo como inteiro.

| id | name | school_grade_id | academic_year |
|---:|---|---:|---:|
| 1 | 7A | 4 | 2026 |
| 2 | 7B | 4 | 2026 |
| 3 | 8A | 5 | 2027 |

Neste exemplo, `school_grade_id = 4` aponta para [[SCHOOL GRADE]] (FUNDAMENTAL_2, ano 2) e `school_grade_id = 5` para o ano 3. O ano letivo `2026` é diferente do campo `SchoolGrade.ano`.
