# Período acadêmico

`AcademicPeriod` contém `id`, `name` e `number`. Não possui relação com uma entidade de ano acadêmico no modelo atual.

| id | name | number |
|---:|---|---:|
| 1 | 1º Bimestre | 1 |
| 2 | 2º Bimestre | 2 |
| 3 | 3º Bimestre | 3 |
| 4 | 4º Bimestre | 4 |

Notas fazem referência ao período por `period_id`; veja [[GRADE]].
