# Exemplos de dados

As notas desta pasta explicam entidades e relações usando dados fictícios. Elas **não** contêm dados para login e não são scripts SQL para execução.

- [[USERS]] — contas e perfis de aluno, professor e diretor.
- [[SCHOOL GRADE]] — etapa escolar.
- [[CLASSROOM]] — turma.
- [[ENROLLMENT]] — matrícula de aluno em uma turma.
- [[SUBJECT]] — disciplina.
- [[TEACHING ASSIGNMENT]] — vínculo professor/turma/disciplina.
- [[ACADEMIC PERIOD]] — período acadêmico.
- [[GRADE]] — nota.
- [[ATTENDANCE]] — presença.
